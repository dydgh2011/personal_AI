# 학습 모델 설계: 중복 내용, 망각, 숙련도 채점

상태: **설계안** (2026-11-22). 구현은 learning 서비스(숙련도 계산)와 knowledge 서비스(원본·증거) 단계에서 합니다.
원칙: AI는 문제를 만들고 정해진 기준(루브릭)으로 채점만 합니다. 숫자는 아래 공식대로 코드가 계산합니다.

## 1. 같은 내용을 여러 자료에서 배울 때 (예: STA256 + 통계 교재)

**핵심: "자료"와 "개념"을 나눕니다. 숙련도는 자료가 아니라 개념에 붙습니다.**

```
개념 지도 (topic 문서, 자료와 무관하게 하나씩)
  조건부 확률 ──prerequisite──▶ 베이즈 정리 ──prerequisite──▶ 베이즈 추론
        ▲ covers(비중, 깊이)          ▲ covers               ▲ covers
  STA256 3주차 슬라이드        STA256 Test 1 3번 문항     Hogg 교재 1.4절, 11장
  (course: STA256)            (증거)                    (교재: 다음 학기 자습)
```

- **과목 = 개념 지도의 한 "보기"**: STA256은 "이 개념들을 이 비중으로 다룬다"는 목록(강의계획서·주차·시험 배점)입니다.
- **교재를 읽으면**: 장마다 개념을 뽑아 기존 개념과 맞춥니다.
  - 이름·별칭이 같거나 의미 검색 유사도가 높으면(약 0.8 이상) "같은 개념 후보"로 올리고, Claude Code나 Kelly가 확인합니다.
  - 같은 개념이면 `covers` 링크만 추가합니다. 새 문서를 만들지 않습니다.
  - 새 개념이면 새 topic 문서를 만들고 선수 개념에 연결합니다.
  - 같은 개념을 더 깊게 다루면 하위 개념(`part_of`)을 추가합니다. 예: "베이즈 정리 · 연속형".
- **증거도 개념에 쌓입니다.** STA256에서 푼 문제와 교재로 푼 문제가 같은 "베이즈 정리"의 증거가 됩니다.
  - 그래서 교재로 더 공부하면 STA256 숙련도도 올라갑니다(실제로 더 아는 것이니 맞습니다).
  - 같은 증거를 두 번 세지도 않습니다.
- **원본 수준의 중복**
  - 같은 파일은 해시가 같아서 이미 건너뜁니다(구현됨).
  - 판만 다른 슬라이드(거의 같은 내용)는 나중에 유사도로 "같은 자료의 다른 판"으로 묶습니다. 지우지 않습니다.

## 2. 망각(휘발성): 기록은 100%인데 3년 뒤에는 잊었을 때

### 연구에서 확인한 것

- **망각 곡선은 처음에 빠르고 점점 느려지며, 지수보다 거듭제곱 곡선이 실제 데이터에 더 잘 맞습니다.** FSRS(Anki의 최신 복습 알고리즘)는 기억 가능성을 `R(t) = (1 + 19/81 · t/S)^(-0.5)`로 계산합니다. S(안정도)는 기억 확률이 90%로 떨어지는 날 수예요. 복습에 성공할 때마다 S가 커지고, 잊었다가 다시 맞히면 더 크게 커집니다(간격 효과).
- **Duolingo의 반감기 회귀(HLR, Settles & Meeder 2016)**: 단어마다 "반감기"를 학습 기록으로 예측해 `p = 2^(-경과/반감기)`로 기억 확률을 계산합니다. 이전 방식(Leitner)보다 오차가 거의 절반으로 줄었습니다.
- **기술 감퇴 메타분석(Arthur 외 1998)**: 쓰지 않으면 잃는 양이 커집니다. 1년 넘게 안 쓰면 효과 크기 약 −1.4. 인지적·정확성 과제가 신체적·속도 과제보다 더 많이 잊힙니다. 2025년 메타분석: 절차적 기술은 정확도 기준 약 6.5개월이면 향상분의 절반을 잃습니다.
- **Bahrick의 장기 기억 연구**: 아주 많이 연습한 내용은 수십 년 남습니다(permastore). 고등학교 대수는, 미적분 이상을 계속 들어서 대수를 계속 "쓴" 사람에게는 50년 뒤에도 남아 있었습니다. **사용이 곧 복습**이라는 뜻입니다.

### 설계

개념마다 숫자를 둘로 나눕니다.

| | 뜻 | 줄어드나 |
|---|---|---|
| **도달 수준** | 증거로 확인된 최고 실력 (IRT θ, 아래 3절) | 줄지 않음 (기록) |
| **기억 상태** | 안정도 S, 마지막 확인 날짜, 지금의 기억 가능성 R(t) | 시간이 지나면 줄어듦 |

- **현재 숙련도** = 도달 수준을 기억 가능성으로 깎은 값. 화면에는 신뢰도도 같이 나옵니다(최근 확인 / 추정 / 오래됨).
- **S를 바꾸는 사건** (강한 순서)
  1. 시험 문제·확인 퀴즈에서 기억해서 맞힘 → S가 크게 증가. 틀리면 S 감소, 도달 수준도 다시 계산.
  2. 실제 사용(과제, 코딩, 다른 과목에서 씀, 남에게 설명) → 암묵적 복습. 중간 정도 증가.
  3. 다시 읽기만 함 → 복습으로 거의 치지 않음(기억해 내기가 아니기 때문).
- **선수 개념 전파**: 상위 개념을 쓰면 선수 개념도 약하게 복습한 것으로 칩니다(Bahrick의 대수 효과).
- **지식 종류별 시작값**: 사실 암기는 빨리, 개념 이해는 중간, 절차·코딩 기술은 천천히 잊힌다고 보고 S의 시작값과 증가율을 다르게 둡니다. 실제 확인 결과가 쌓이면 사람(나)에게 맞게 보정합니다.
- **확인 필요 알림**: 중요한 개념의 R이 0.8 아래로 내려가면 "확인 필요"로 표시합니다. Kelly가 2~3문제짜리 짧은 퀴즈를 내거나 planner에 복습 블록을 제안합니다. 결과로 S와 도달 수준을 다시 맞춥니다.
- **예시 (3년 방치)**: 도달 100%, S=60일, 이후 사용 없음 → `R(1095일) = (1 + 0.2346 × 1095/60)^(-0.5) ≈ 0.44`. 현재 약 44%, "오래됨·확인 필요". 퀴즈 3문제로 실제 수준을 다시 확인합니다.
- **반대로 오래 남는 것**: 몇 달에 걸쳐 여러 번 성공한 개념은 S가 몇 년 단위로 커져서 자연히 "오래 감"으로 나옵니다.

## 3. 숙련도 채점 기준

```
분야 (Statistics)          넓이: 분야 기준 지도 중 숙련한 비율 / 깊이: 숙련한 최고 수준
 └ 과목 (STA256)            개념 숙련도의 가중 평균 (가중치 = 강의 시간·시험 배점 비율)
    └ 개념 (베이즈 정리)     도달 수준 θ (IRT) × 기억 상태 R(t)
       └ 증거               시험 문항, 확인 문제, 과제, 사용 기록 (난이도·유형·힌트·시간)
```

**증거와 신뢰도**

| 증거 | 신뢰도 | 비고 |
|---|---|---|
| 공식 시험·퀴즈 점수 | 높음 | 문항별 점수(Crowdmark)가 있으면 문항마다 개념에 연결 |
| 확인 문제 (AI 출제) | 높음 | 정답·루브릭을 **풀기 전에 고정**. 힌트를 쓰면 감점. "찍었어요"라고 하면 낮게 반영 |
| 과제·실제 사용 | 중간 | 기억 상태(S)에 주로 반영 |
| 진도 (몇 주차까지 공부) | 숙련도 아님 | "배운 범위"만 정함 |
| 자기 평가 | 낮음 | 증거가 없을 때 시작값으로만 사용 |

- **도달 수준(θ)**: 문제마다 난이도 b(1~5에서 시작해 실제 정답률로 보정)를 둡니다. 정답 확률은 `P = 1 / (1 + e^-(θ − b))`이고, 풀 때마다 `θ ← θ + K·(결과 − P)`로 갱신합니다. 어려운 문제를 맞히면 크게, 쉬운 문제를 틀리면 크게 움직입니다. 말씀하신 난이도 가중치가 여기 들어갑니다.
- **표시**: 보통 난이도(b=3) 문제를 맞힐 확률(0~100). 증거가 3개 미만이면 "아직 모름".
- **단계**: 시작 전 / 접해봄 / 익히는 중 / 숙련 / 완전 숙달.
  - 숙련: 보통 이상 난이도를 서로 다른 날에 3문제 이상, 힌트 없이.
  - 완전 숙달: 어려운 문제 포함, 7일 이상 지나서 다시 맞힘.
- **과목**: 개념 비중으로만 가중 평균합니다. 난이도는 θ에 이미 들어 있어서 다시 곱하지 않습니다. 또 곱하면 어렵지만 작은 개념 하나가 과목 점수를 좌우합니다.
- **분야**: 과목 점수의 평균이 아니라 **분야 기준 개념 지도**(입문~대학원 수준 표시)에 내 개념을 맞춰서 넓이(%)와 깊이(수준)로 보여줍니다. 여러 과목에 겹친 개념은 한 번만 셉니다.
