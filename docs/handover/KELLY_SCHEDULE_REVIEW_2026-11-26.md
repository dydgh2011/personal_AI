## 🟢 낮음 / 작은 버그
- `todo_progress`: 예상 분에 닿으면 자동 완료(S3). "2시간 했어"가 끝났다는 뜻이 아닐 수 있음.
- 시안 안 겹침 경고: 한 번짜리 항목(날짜)과 매주 항목(요일)을 비교하지 못함(`occurrenceDays`).
- `confirm`은 여러 날을 쓰다 Google 오류가 나면 일부만 반영(다시 하면 이어서 됨).
- broker 쓰기 제한 30/분에 `dryRun` 미리보기도 포함.
- `calendar_connect`는 Kelly가 언제든 시작 가능(링크는 127.0.0.1로만 돌아오고 15분 유효 → 위험 낮음).

## UX 개선 제안
1. **"넣어줘" 한 흐름**: 지금은 할 일 → generate → confirm 세 단계라 주인이 "넣어줘"라고 하면 Kelly가 엉뚱한 날짜를 확정하려 했다(11/26 04:46). 할 일 추가 때 "언제 할지"를 같이 묻고 블록 확정까지 한 번에.
2. **실제 기록 구조**: 블록·일정에 실제 시작·끝·상태(끝냄/늦음/건너뜀)와 주인이 말한 이유를 쌓고, 과목·종류별 "예상 대비 실제" 비율로 다음 예상 시간을 고친다.
3. **알림 정리**: 묶음 알림(다음 2~3개를 한 번에), 식사·쉬기·이동은 알림 끄기, 아침 브리핑을 수면 끝 뒤로, 밤 초안 시각 설정.
4. **다가오는 시험·마감 목록 조회** 동작(예: 30일 안 시험·마감).
5. **응답 끝 "이번에 바뀐 것" 요약을 코드가 붙임** → 도구 없이 "반영했어"라고 하면 바로 드러난다.
6. 시험·퀴즈는 할 일이 아니라 일정(+시험 표시)으로, 준비만 할 일로.
